Web Application:

env (assuming you already have a venv folder by running: python3 -m venv venv):
source venv/bin/activate

installing python requirements(backend):
pip install -r server/requirements.txt    

installing React requirements (frontend):
cd client
npm install

backend: 
cd server
uvicorn main:app --host 0.0.0.0 --port 8000
(production: venv/bin/gunicorn -k uvicorn.workers.UvicornWorker main:app --bind 0.0.0.0:8000)

frontend: 
cd client
npm run dev -- --host 0.0.0.0


Ngrok (testing - ngrokservername -> localhost:5678):
ngrok http 5678 

n8n:
n8n start


Want to inject data?
python3 -m injectData.inject_tires
python3 -m injectData.inject_oils
...
