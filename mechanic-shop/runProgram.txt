Web Application:

env (assuming you already have a venv folder by running: python3 -m venv venv):
source venv/bin/activate

backend: 
cd server
uvicorn main:app --reload --port 8000

frontend: 
cd client
npm run dev


Ngrok (testing - ngrokservername -> localhost:5678):
ngrok http 5678 

n8n:
n8n start


Want to inject data?
python3 -m injectData.inject_tires
python3 -m injectData.inject_oils
